This pass adds a complete local-only Basket → Collection → Checkout → Preview complete journey without adding payment, submission, availability guarantees, or a second basket state. Optional sample details remain in component memory, Back/edit preserves them, completion is idempotent, and basket edits invalidate a finished preview.

The measured opening mismatch was corrected inside the unchanged 6.5-second duration: the return begins early enough for its final delayed photograph to finish before the complete state replaces the animation. The leaf overlay now becomes eligible only after Chromium reports its first decoded frame as presented; each run still owns one load, initial seek, play, commit and unlock. Native compositor captures with timing metadata are retained in the local review evidence.

Catalogue media now has request-scoped decoded state, one bounded automatic recovery, accessible manual retry, and stale request protection. Synthetic long-content contact testing preserves exact controlled input and fixes the reproduced grid overflow without deleting or rewriting content.

The permanent structure uses warm storybook diffuse derivatives of the existing CC0 Rough Wood source, keeps its physical normal/roughness response, adds geometry-linked contact shade at four post/beam joints, and removes the visible rear metal tracks. First-paint and settled posters were regenerated from the final scene. The single fixed header has full and compact states driven from logical scroll position.

Audio source levels were measured before adjustment. Species-specific trims replace the previous shared assumptions, and animal/bird calls no longer win twice by also ducking the music. Same-run application audio is retained for listening review; automated evidence cannot establish subjective speaker/headphone approval.

Six paired AB/BA software-rendered benchmark runs retained an effectively identical median frame interval while the candidate reduced material decoded bytes and scene draw calls. Candidate p95/max intervals were less stable, so the result is reported as a quality tradeoff with no physical-device or GPU performance claim.
